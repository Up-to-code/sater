# Arabic core catalog provenance

`code-oss-arabic-main.i18n.json` is the MIT-licensed Arabic Code-OSS catalog
from [Arabic-for-visual-studio-code](https://github.com/almhajer/Arabic-for-visual-studio-code),
revision `105d30040ec5df60cb2ca553402e245d375bb660` (2026-06-16).

It is checked in as a deterministic build input so packaged Sater launches do
not depend on a developer having a language-pack extension installed. Refresh
it deliberately when the Code-OSS base version changes, preserving the
upstream license in `ARABIC_PACK_LICENSE.md`.
